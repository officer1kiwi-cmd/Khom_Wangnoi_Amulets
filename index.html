📝 ลงประกาศบนกระดาน คม วังน้อย

🤝 ศูนย์ดูแลและตอบข้อซักถาม คม วังน้อย

1. สแกนพระเครื่องทำงานอย่างไร? -> ระบบจะทำลูปสแกนดึงภาพมาเปรียบเทียบกับภาพพระแท้ที่แอดมินอัปโหลดไว้ทุกภาพจนครบสารบบโดยอัตโนมัติ
2. การลบหรือแก้ไขประกาศทำอย่างไร? -> กดปุ่มลบสีแดงที่ตัวประกาศแล้วระบุรหัส PIN 4 หลักที่ท่านตั้งไว้ตอนลงประกาศครั้งแรกครับ
3. แอดมินสามารถช่วยลบประกาศให้ได้ไหม? -> ได้ครับ แอดมินคมมีสิทธิ์เหนือระบบสามารถกรอกพินหลักแอดมินเพื่อเคลียร์ประกาศได้ทันที
4. เปิดระบบประมูลพระเครื่องอย่างไร? -> ตอนกรอกแบบฟอร์มลงประกาศ ให้สลับหมวดหมู่รูปแบบการซื้อขายเป็น "เปิดระบบประมูล" ครับ
5. ตลาดอุปกรณ์เปิดรับสินค้าประเภทใดบ้าง? -> เปิดรับตลับพระ ทองคำ เลี่ยมกรอบพลาสติก กล้องส่องพระ สร้อยห้อยคอ และโต๊ะหมู่บูชาทุกประเภท
6. เบอร์โทรติดต่อเลข 0 ตัวหน้าจะตกหล่นไหม? -> ไม่หล่นแน่นอนครับ ระบบเซฟลงฐานข้อมูลเป็นข้อความสายตรงปลอดภัยร้อยเปอร์เซ็นต์
7. การขอรับป้าย "ร้านค้าแนะนำ" ทำอย่างไร? -> สามารถพิมพ์ข้อความแนบหลักฐานทักกล่องแช้ตสายตรงด้านล่างนี้เพื่อให้แอดมินอนุมัติพิจารณาครับ
8. การเสนอราคาประมูลต้องโอนมัดจำไหม? -> ระบบเป็นศูนย์กลางเปิดราคาติดต่อโดยตรง แนะนำให้นัดรับตรวจเช็คเพื่อความปลอดภัยทั้งสองฝ่าย
9. อยากดันประกาศให้ขึ้นมาอยู่แถวบนสุดทำอย่างไร? -> สามารถใช้สิทธิ์ลบประกาศอันเดิมออกแล้วทำการกดลงประกาศใหม้อีกครั้งได้ฟรีไม่มีจำกัดครับ
10. ระบบรองรับผู้ใช้งานผ่านคอมพิวเตอร์ด้วยไหม? -> ออกแบบระบบแสดงผลแบบ Responsive คลุมหน้าจอมือถือสวยงามและใช้งานบนหน้าจอคอมพิวเตอร์ได้ดีเช่นกัน
