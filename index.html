📝 ลงประกาศพระเครื่องของท่าน

🤝 สายตรงระบบดูแล คม วังน้อย

1. สแกนพระเครื่องทำงานอย่างไร? -> ระบบจะนำภาพของท่านเข้าไปสแกนเทียบกับคลังรูปพระแท้ของแอดมินทุกรูปทีละภาพจนครบครับ
2. การลบหรือแก้ไขประกาศทำอย่างไร? -> กดปุ่มลบสีแดงที่ตัวประกาศแล้วกรอก PIN 4 หลักที่ตั้งไว้ตอนแรกครับ
3. แอดมินสามารถลบประกาศคนอื่นได้ไหม? -> ได้ครับ แอดมินกรอกรหัส PIN สูงสุดแทนรหัสเจ้าของประกาศเพื่อลบได้ทันที
4. ระบบประมูลทำงานอย่างไร? -> สมาชิกสามารถกดเสนอราคาสูงขึ้นไปทับราคาเดิมได้ทันที
5. เบอร์โทรเลข 0 ตัวหน้าจะหายไหม? -> ระบบเซฟลง Google sheet เป็นรูปแบบตัวหนังสือ ปลอดภัยเลข 0 ไม่หายชัวร์ครับ
