ไม่มีประวัติข่าวสารเพิ่มเติมในขณะนี้

ศูนย์สอบถามข้อซักถาม คม วังน้อย

1. สแกนตรวจสอบพระเครื่องทำงานอย่างไร? -> ระบบจะดึงภาพแม่แบบพระแท้จากระบบแอดมินมาทำลูปสแกนวิเคราะห์เชิงเปรียบเทียบจุดต่อจุดจนเสร็จสิ้นอัตโนมัติครับ
2. วิธีการลบหรือปรับเปลี่ยนสถานะทำอย่างไร? -> กดปุ่ม "จัดการสถานะ/ลบ" ท้ายการ์ดประกาศของท่าน แล้วระบุรหัส PIN 4 หลักที่ระบุไว้ตอนลงทะเบียนเพื่อแก้ไขได้ทันทีครับ
3. แอดมินสายตรงช่วยเหลือกรณีลืมรหัส PIN ได้ไหม? -> ได้แน่นอนครับ แอดมินมี Master PIN สูงสุดสามารถตรวจสอบคิว และเคลียร์โพสต์ผิดกฎให้ได้ทันที
4. ตั้งค่าระบบประมูลพระเครื่องอย่างไร? -> ขณะพิมพ์แบบฟอร์มลงประกาศ ให้ปรับเปลี่ยนช่องรูปแบบการซื้อขายเป็น "เปิดระบบประมูล" และใส่ราคาเปิดตัวแรกเริ่มครับ
5. หมวดตลาดอุปกรณ์รองรับสินค้าแบบไหนบ้าง? -> รองรับตลับพระทองคำ กรอบพลาสติกเลี่ยมพระ เลนส์กล้อง Zeiss สร้อยพระ และเครื่องมือบูชาทุกชนิดอย่างถูกกฎหมายครับ
6. หมายเลขโทรศัพท์เลข 0 นำหน้าจะหายไปในระบบสเปรดชีตไหม? -> ปลอดภัยร้อยเปอร์เซ็นต์ครับ หลังบ้านใส่เครื่องหมายฝากสายอักขระพิเศษตัวหน้าไว้ ทำให้เบอร์ครบสิบหลักสมบูรณ์แบบครับ
7. การขอรับสิทธิ์ป้าย "ร้านค้าแนะนำ" ทำอย่างไร? -> ต้องยื่นหลักฐานบัตรและประวัติพระแท้ให้แอดมินพิจารณาตรวจสอบเพื่อยืนยันตัวตนติดสัญลักษณ์สีทองโดดเด่นพิเศษเหนือระดับ
8. ระบบการเสนอราคาประมูลมีการมัดจำทรัพย์หรือไม่? -> แพลตฟอร์มเป็นตัวกลางเชื่อมต่อกระดานสายตรง แนะนำให้นัดพบตรวจองค์จริง ณ สนามพระเครื่องเพื่อความปลอดภัยชัวร์ที่สุดครับ
9. อยากดันโพสต์ประกาศให้อยู่ด้านบนสุดต้องทำอย่างไร? -> ท่านสามารถใช้รหัส PIN ลบประกาศอันเดิมออกแล้วทำการกดลงโพสต์ประกาศเนื้อหาเดิมซ้ำใหม่อีกครั้งได้ทันทีโดยไม่มีค่าบริการใดๆ
10. แอปนี้เปิดใช้งานบนจอเครื่องคอมพิวเตอร์พกพาได้หรือไม่? -> ออกแบบโค้ดเป็นระบบ Responsive Web สามารถยืดหดคลุมสัดส่วนตามสเกลได้คมชัดแจ่มแจ้งทั้งจอพีซี แท็บเล็ต และสมาร์ทโฟนครับ
11. กล่องแชทความคิดเห็นใต้ประกาศเก็บประวัติอย่างไร? -> ประวัติจะผูกติดกับ ID ประกาศชิ้นนั้นๆ แบบโปร่งใส เพื่อให้สมาชิกท่านอื่นเห็นประวัติความต้องการและการจองได้เรียลไทม์
12. ติดต่อแอดมิน คม วังน้อย โดยตรงผ่านเว็บทำอย่างไร? -> ท่านสามารถกรอกกล่องข้อความติดต่อสายตรงส่วนตัวที่เมนูด้านล่างนี้เพื่อส่งข้อมูลตรงสู่ใบรายงานแอดมินได้ทันทีครับ
